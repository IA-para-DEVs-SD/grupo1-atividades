Crie uma API REST simples em Python utilizando FastAPI. Ela deve ter 3 endpoints:
- um GET
- um POST
- um DELETE

A Api será utilizada para um cadastro de produto

Entidade: Item (id, nome, descricao)

- Endpoint GET /items: retorna lista de itens
- Endpoint POST /items: cria um novo item
- Endpoint DELETE /items/{id}: remove item pelo id
- Usar lista em memória como banco de dados
- Código organizado e pronto para execução
